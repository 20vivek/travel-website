# Travel.

A responsive travel website for showcasing tour packages and making booking simple. Visitors can browse adventure and tour packages, explore the services on offer, and head to the booking page to plan their trip.

**Live demo:** https://20vivek.github.io/travel-website/

---

## Features

- **Hero slider** with calls to action to explore destinations
- **Services section** covering adventure, tour guide, trekking, campfire, off-road, and camping
- **Featured packages** with quick "Book now" links
- **Promotional banner** for seasonal offers and discounts
- **Dedicated pages:** Home, About, Packages, and Book
- **Booking page** for reserving a tour
- **Responsive layout** that adapts to desktop, tablet, and mobile screens
- **Footer** with quick links, contact info, and social links

## Pages

| Page     | Description                                              |
| -------- | -------------------------------------------------------- |
| Home     | Hero slider, services, about preview, packages, and offer |
| About    | Information about the agency                             |
| Packages | Full list of available tour packages                     |
| Book     | Form to book a tour                                      |

## Getting Started

### Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/20vivek/travel-website.git
   ```
2. Open the project folder:
   ```bash
   cd travel-website
   ```
3. Open `index.html` in your browser, or serve it with a local server such as the VS Code Live Server extension.

## Project Structure
